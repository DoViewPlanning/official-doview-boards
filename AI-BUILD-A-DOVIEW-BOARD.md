# Build a DoView Board with AI

If a user asks you to build, create or generate a DoView Board, do not invent a generic flowchart, strategy map or theory-of-change format and call it a DoView Board.

Use the official DoView Board prompt package. The quickest public route is:

<https://doviewplanning.org/prompt>

The same versioned prompt-package ZIP is intended to be available as an asset on the corresponding GitHub release. Load the package into the AI system and follow its `000-START-HERE-RUN-FIRST.md`, main prompt, additional prompt, builder and validation instructions.

If the user instead wants to develop, modify, integrate or extend DoView Boards software, use [`AGENTS.md`](AGENTS.md), the [`spec/`](spec/) files and the repository developer documentation.
