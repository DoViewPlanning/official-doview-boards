# DoView Boards V1.4.3 release notes

**Version:** V1.4.3  
**Release date:** 2026-08-14  
**Saved schema:** V1.3.9

Extensive testing of the prompt was carried out to improve the comprehensiveness and defensibility of links between This–Then Boxes, between This–Then Boxes and How Boxes, and between How Boxes. V1.4.3 moves normal ChatGPT and Claude chat workflows to a two-step process. Step 1 creates the base DoView Board, including links between This–Then Boxes. Step 2 adds links between This–Then Boxes and How Boxes, and between How Boxes.

The release also finalises the Step-specific delivery filenames, requires exactly two user-facing download links, and requires each supporting ZIP to contain the standalone HTML, same-stem canonical JSON, prompt-used record and Step-correct audit. The HTML inside the ZIP must be byte-identical to the separately delivered HTML.

Strict validation checks technical consistency, provenance, counts, graph and mapping integrity, JSON/HTML equality and Step 1-to-Step 2 structure preservation. It does not prove that every causal or mapping judgement is correct. Human and subject-matter review remains required before operational use.
